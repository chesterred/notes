Grok AI image generator: prompt habits that stop the plastic look

2026-11-26 · working notes

The single biggest improvement came from naming a light source instead of a mood. "Golden hour" produced the usual orange wash; "single window, north-facing, overcast" gave skin tones that did not need retouching. Once I started writing lighting like a photographer rather than an adjective, the output stopped looking synthetic.

Rate limits are the practical constraint for batch work. The free allowance resets daily and is generous enough for a moodboard, not for a client deck. Current limits and the paid tiers are described on Grok AI Image Generator, which is worth reading before you plan a shoot around it.

Text rendering is still unreliable. Short words on signs usually work, longer phrases drift into pseudo-letters. If a poster or label matters, generate the image clean and set the type in an editor. Composition control through the prompt is decent, but there is no true inpainting workflow yet, so fixing one bad hand means regenerating.

Verdict: strong for editorial-style stills when prompted like a photo brief; weak on text and fine editing.
